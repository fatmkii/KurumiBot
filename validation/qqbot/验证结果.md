## 已固化的接入方式

- 凭据读取：兼容根目录 `.env` 中的 `QQ_APP_ID`、`QQ_APP_SECRET`；凭据不写入代码或日志。
- 依赖环境：Python 3.12、uv，使用 `uv.lock` 固定 qqbot-agent-sdk 1.2.2 及依赖。
- REST 初始化：创建 `httpx.AsyncClient`，调用 `QQApiClient.setup(http_client)`。
- WebSocket：获取 token 和 Gateway 后启动；补齐 `WSCallbacks` 必填回调，使用线程锁保护会话读写。正常退出调用 `async_stop()` 并关闭 HTTP 客户端。
- 私聊事件：使用 `EventParser` 解析 `C2C_MESSAGE_CREATE`，取事件的用户 openid 作为上传和发送目标。
- 本地图片：调用 `MediaUploader.upload(chat_type="c2c", ...)`，SDK 实际完成申请上传、PUT 分片、确认分片和完成上传。
- 回复：创建 `RICH_MEDIA` 消息，把上传结果放入 `MediaInfo.file_info`，带入站 `msg_id` 和 `msg_seq=1`，调用 `post_c2c_message`。
- 去重：以渠道、会话及入站消息 ID 为键；日志记录脱敏标识、耗时、HTTP 状态和 trace ID，不输出 token 或上传凭证。

运行命令及切换图片方法见 `README.md`。本次为一条 PNG 私聊消息验证；连续消息、不同用户、JPG、重复事件、缺失图片、30 分钟运行及意外断线重连仍未验证。

最小探针依据安装版本源码实现，已实测鉴权失败记录、鉴权成功、Gateway、WebSocket 就绪及心跳、私聊上传和发送路径；群聊上传及发送仍待实测。官方源码参考：[qqbot-agent-sdk](https://github.com/tencent-connect/qqbot-agent-sdk)。
